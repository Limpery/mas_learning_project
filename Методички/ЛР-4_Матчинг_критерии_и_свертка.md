## 1. Теоретическая справка

В работе № 3 заказ соглашался на первый предложенный вариант. Теперь агент заказа становится **лицом, принимающим решение**: у него появляются критерии, по которым он оценивает предложения, и способ свести несколько критериев к одному числу.

Это центральная идея курса. В «Теоретических основах создания систем ЭИ» (раздел 2.3) цель агента задаётся **функцией удовлетворённости** — взвешенной суммой компонент по критериям, где сумма весов равна единице. В этой работе мы строим её упрощённый вариант: без бюджета и компенсаций, но уже с нормировкой и весами.

Три критерия для агента заказа:

- время получения заказа;
- время доставки заказа;
- стоимость доставки.

Критерии разноразмерны — часы нельзя складывать с рублями. Поэтому каждое значение **нормируется** линейной функцией в отрезок [0; 1]: для убывающего критерия минимальному значению соответствует 1, максимальному — 0; для возрастающего наоборот.

**Матчинг** — установление соответствия между потребностью и возможностью по формальным признакам: тип груза, масса, объём. Матчинг выполняется до переговоров о цене и резко сокращает перебор: заведомо неподходящие пары не обсуждаются вовсе. Обратите внимание, что матчинг разделён между двумя агентами: по типу груза отсеивает заказ (он знает, кому вообще писать), по массе и объёму — курьер (это его собственные ограничения, и он вправе не раскрывать их заранее).

Литература: пособие по Python (СамГТУ, 2024), глава 4; «Теоретические основы» (СамГТУ, 2023), раздел 2.3.

### Шаг 3. Функции нормировки критериев

Обе функции статические и помещаются в базовый класс агента — они понадобятся всем классам агентов.

```python
    @staticmethod
    def get_decreasing_kpi_value(value: float, min_value: float, max_value: float):
        """
        Значение убывающей линейной функции, нормированное к единице.
        f(min_value) == 1, f(max_value) == 0
        """
        if max_value == min_value:
            return 1
        if value > max_value or value < min_value:
            return -1
        if isinstance(value, float) and abs(value - min_value) < 0.000001:
            return 1
        if isinstance(value, float) and abs(value - max_value) < 0.000001:
            return 0
        return 1 - (value - min_value) / (max_value - min_value)
```

```python
    @staticmethod
    def get_increasing_kpi_value(value: float, min_value: float, max_value: float):
        """
        Значение возрастающей линейной функции, нормированное к единице.
        f(min_value) == 0, f(max_value) == 1
        """
        if max_value == min_value:
            return 1
        if value > max_value or value < min_value:
            return -1
        if isinstance(value, float) and abs(value - min_value) < 0.000001:
            return 0
        if isinstance(value, float) and abs(value - max_value) < 0.000001:
            return 1
        return (value - min_value) / (max_value - min_value)
```

Разберитесь, почему в обеих функциях отдельно обработаны случаи совпадения границ и выхода за диапазон, и что означает возвращаемое значение −1.

### Шаг 4. Оценка вариантов

Агент заказа сначала находит границы диапазонов по всем полученным вариантам, затем оценивает каждый вариант по трём критериям.

```python
    def __evaluate_variants(self):
        """Оцениваем варианты по критериям и расширяем информацию о них"""
        if not self.possible_variants:
            return
        all_start_times = [var.get('time_from') for var in self.possible_variants]
        min_start_time = min(all_start_times)
        max_start_time = max(all_start_times)
        all_finish_times = [var.get('time_to') for var in self.possible_variants]
        min_finish_time = min(all_finish_times)
        max_finish_time = max(all_finish_times)
        all_prices = [var.get('price') for var in self.possible_variants]
        min_price = min(all_prices)
        max_price = max(all_prices)
```

```python
        for variant in self.possible_variants:
            start_efficiency = self.get_decreasing_kpi_value(
                variant.get('time_from'), min_start_time, max_start_time)
            finish_efficiency = self.get_increasing_kpi_value(
                variant.get('time_to'), min_finish_time, max_finish_time)
            price_efficiency = self.get_decreasing_kpi_value(
                variant.get('price'), min_price, max_price)
            variant['start_efficiency'] = start_efficiency    # [0; 1]
            variant['finish_efficiency'] = finish_efficiency  # [0; 1]
            variant['price_efficiency'] = price_efficiency    # [0; 1]
```

**Внимание.** Направление каждой из трёх функций (возрастающая или убывающая) определяет смысл критерия.     def __run_planning(self):
```python
        if not self.possible_variants:
            logging.info(f'{self} - нет возможных вариантов для планирования')
            return
        self.__evaluate_variants()
        sorted_vars = sorted(self.possible_variants,
                             key=lambda x: x.get('total_efficiency'), reverse=True)
        best_variant = sorted_vars[0]
        best_variant_address = self.dispatcher.reference_book.get_address(

        request_message = Message(MessageType.PLANNING_REQUEST, best_variant)
        self.send(best_variant_address, request_message)
```

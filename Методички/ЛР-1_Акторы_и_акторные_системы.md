## 1. Теоретическая справка

**Актор** — вычислительная сущность, которая в ответ на полученное сообщение может: изменить своё внутреннее состояние, отправить сообщения другим акторам, создать новых акторов. Модель предложена Карлом Хьюиттом в 1973 году и лежит в основе Erlang/OTP, Akka, Microsoft Orleans, Ray.

Три свойства, ради которых модель нужна нам в курсе:

- **Нет разделяемого состояния.** У актора есть только его собственные поля. Дотянуться до них извне нельзя — можно лишь послать сообщение.
- **Взаимодействие только сообщениями.** У актора нет методов, которые можно вызвать. Есть адрес, по которому ему отправляют сообщение, и обработчик, который это сообщение принимает.
- **Асинхронность.** Отправитель не ждёт ответа и не знает, когда сообщение будет обработано.

Именно поэтому акторная модель — естественный «движок» для мультиагентных систем: агент не может залезть в чужое состояние и обязан договариваться.

Важно сразу развести два понятия, к которым мы вернёмся в конце курса. **Актор — это вычислительное тело**: модель параллелизма, механизм доставки сообщений. **Агент — это семантический разум**: у него есть цель, критерии, предпочтения, он принимает решения и ведёт переговоры. Агент строится поверх актора. В этой работе мы строим тело; агентом оно станет в работе № 2.

## 3. Порядок выполнения

### Шаг 1. Простейший актор

Создайте файл `main.py`. Импортируйте пространство имён фреймворка и опишите класс актора, унаследовав его от `Actor` и переопределив метод `receiveMessage`. Этот метод вызывается каждый раз, когда актор получает сообщение, и принимает само сообщение и адрес отправителя.

```python
from thespian.actors import *


class SimplestActor(Actor):
    """Простой актор, который в будущем станет агентом"""

    def receiveMessage(self, msg, sender):
        print(f'Актор с адресом {self.myAddress} получил {msg} от {sender}')
```

Точка входа создаёт акторную систему, порождает в ней экземпляр актора и отправляет ему сообщение. Обратите внимание: `createActor` возвращает **не объект, а адрес** — обратиться к полям и методам актора вы не сможете.

```python
if __name__ == "__main__":
    # Создаем систему акторов, внутри которой они будут жить
    actorSystem = ActorSystem()
    # Создаем экземпляр созданного нами класса и сохраняем его адрес
    actorAddress1 = actorSystem.createActor(SimplestActor)
    # Отправляем по сохраненному адресу сообщение
    actorSystem.tell(actorAddress1, "Первое сообщение")
```

Запустите программу командой `python main.py`. В консоли должна появиться строка вида:

```
Актор с адресом ActorAddr-/A~a получил Первое сообщение от ActorAddr-System:ExternalRequester
```

### Шаг 5. Взаимодействие акторов разных типов

Опишите два новых класса: актор-число получает своё значение и адрес калькулятора, после чего отправляет значение калькулятору; актор-калькулятор накапливает полученные числа и выводит сумму.

```python
class NumberActor(Actor):
    def __init__(self):
        super().__init__()
        self.value = 0

    def receiveMessage(self, msg, sender):
        print(f'Актор числа с адресом {self.myAddress} получил {msg} от {sender}')
        # Ожидаем словарь со значением числа и адресом актора-калькулятора
        self.value = msg.get('init_value')
        calculator_address = msg.get('calculator_address')
        self.send(calculator_address, self.value)


class CalculatorActor(Actor):
    def __init__(self):
        super().__init__()
        self.values = []

    def receiveMessage(self, msg, sender):
        self.values.append(msg)
        total_sum = sum(self.values)
        print(f'Актор-калькулятор с адресом {self.myAddress} получил {msg} от {sender}, '
              f'итоговая сумма: {total_sum}')
```

Запуск трёх акторов-чисел выглядит так:

```python
    calculator_address = actorSystem.createActor(CalculatorActor)

    number_agent_1 = actorSystem.createActor(NumberActor)
    init_message_1 = {'init_value': 1, 'calculator_address': calculator_address}
    actorSystem.tell(number_agent_1, init_message_1)
```

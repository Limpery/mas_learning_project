## 1. Теоретическая справка

В работе № 1 вся логика актора помещалась в один метод `receiveMessage`, а сообщения были нетипизированными. Для учебного примера это допустимо, для системы из десятка классов агентов — нет: метод превращается в лестницу условий, а любая опечатка в тексте сообщения обнаруживается только на исполнении.

Мультиагентная система требует **стандартизованного протокола переговоров**. Протокол — это перечень допустимых типов сообщений и правила их следования. Поэтому в каркасе появляются:

- **перечисление типов сообщений** (`MessageType`) — закрытый список того, о чём агенты вообще могут говорить;
- **класс сообщения** (`Message`) — тип плюс тело; позже сюда можно добавить время формирования, идентификатор переговоров, приоритет;
- **базовый класс агента** (`AgentBase`) — общая для всех агентов машинерия: хранение подписок и диспетчеризация входящего сообщения нужному обработчику;
- **механизм подписки** — каждому типу сообщения ставится в соответствие метод-обработчик.

Подписка — это не техническая деталь, а содержательный шаг. Актор реагирует на сообщение как на данные; агент реагирует на **событие определённого типа**, для которого у него есть заранее заданное поведение. Отсюда рукой подать до проактивности: агент, у которого есть обработчики событий и собственная цель, может сам инициировать переговоры.

## 2. Порядок выполнения

### Шаг 1. Формат сообщений

Создайте файл `message.py`. Типы сообщений вынесите в перечисление, само сообщение опишите как датакласс из двух полей.

```python
from enum import Enum
from dataclasses import dataclass
from typing import Any


class MessageType(Enum):
    INITIALIZATION = 'Инициализация'
    CREATE_ACTOR = 'Создание актора'
    HELLO_WORLD = 'Приветствие'


@dataclass
class Message:
    """Класс для хранения сообщений"""
    msg_type: MessageType
    msg_body: Any
```

### Шаг 2. Базовый класс агента

Создайте файл `agent_base.py`. Класс `AgentBase` наследуется одновременно от `ABC` и от `Actor`: абстрактность не даёт создать «просто агента», наследование от актора даёт тело.

```python
from abc import ABC
from typing import Dict, Callable, Any
import logging
import traceback

from thespian.actors import Actor, ActorAddress

from message import MessageType, Message


class AgentBase(ABC, Actor):
    """Базовая реализация агента"""

    def __init__(self):
        self.name = 'Базовый агент'
        self.handlers: Dict[MessageType, Callable[[Any, ActorAddress], None]] = {}
        self.subscribe(MessageType.HELLO_WORLD, self.handle_hello_world)
```

### Шаг 3. Механизм подписки

Обработчик — это функция двух аргументов: сообщение и адрес отправителя. Все обработчики хранятся в словаре «тип сообщения → обработчик».

```python
    def subscribe(self, msg_type: MessageType, handler: Callable[[Any, ActorAddress], None]):
        """
        Подписка на события определенного типа
        :param msg_type: Тип события
        :param handler: Обработчик сообщения заданного типа
        """
        if msg_type in self.handlers:
            logging.warning('Повторная подписка на сообщение: %s', msg_type)
        self.handlers[msg_type] = handler
```

### Шаг 4. Диспетчеризация входящих сообщений

Теперь `receiveMessage` не содержит прикладной логики вообще — он только находит обработчик по типу и вызывает его, перехватывая исключения, чтобы падение одного обработчика не убивало агента.

```python
    def receiveMessage(self, msg, sender):
        """Обрабатывает сообщения - запускает их обработку в зависимости от типа."""
        logging.debug('%s получил сообщение: %s', self.name, msg)

        if isinstance(msg, Message):
            message_type = msg.msg_type
            if message_type in self.handlers:
                try:
                    self.handlers[message_type](msg, sender)
                except Exception as ex:
                    traceback.print_exc()
                    logging.error(ex)
            else:
                logging.warning('%s Отсутствует подписка на сообщение: %s',
                                self.name, message_type)
```

### Шаг 5. Перенос приложения-калькулятора на каркас

Создайте файл `number_agent.py`. Агент числа подписывается на сообщение инициализации и в ответ отправляет калькулятору своё значение — уже в виде типизированного сообщения.

```python
from thespian.actors import ActorAddress

from agent_base import AgentBase
from message import Message, MessageType


class NumberAgent(AgentBase):
    def __init__(self):
        super().__init__()
        self.value = 0
        self.subscribe(MessageType.INITIALIZATION, self.handle_initialization)

    def handle_initialization(self, message: Message, sender: ActorAddress):
        print(f'Актор числа с адресом {self.myAddress} получил {message} от {sender}')
        self.value = message.msg_body.get('init_value')
        calculator_address = message.msg_body.get('calculator_address')
        new_message = Message(MessageType.HELLO_WORLD, self.value)
        self.send(calculator_address, new_message)
```

Создайте файл `calculator_agent.py`. Обратите внимание: у этого агента **нет явной подписки** — он переопределяет обработчик базового класса. Это второй способ задать поведение, и он тоже должен быть вам понятен.

```python
from thespian.actors import ActorAddress

from agent_base import AgentBase
from message import Message


class CalculatorAgent(AgentBase):
    def __init__(self):
        super().__init__()
        self.values = []

    def handle_hello_world(self, message: Message, sender: ActorAddress):
        new_value = message.msg_body
        self.values.append(new_value)
        total_sum = sum(self.values)
        print(f'Актор-калькулятор с адресом {self.myAddress} получил {message} '
              f'от {sender}, итоговая сумма: {total_sum}')
```

Точка входа собирает всё вместе:

```python
from thespian.actors import *

from calculator_agent import CalculatorAgent
from number_agent import NumberAgent
from message import Message, MessageType


if __name__ == '__main__':
    actorSystem = ActorSystem()
    calculator_address = actorSystem.createActor(CalculatorAgent)

    number_agent_1 = actorSystem.createActor(NumberAgent)
    init_message_1_data = {'init_value': 1, 'calculator_address': calculator_address}
    init_message_1 = Message(MessageType.INITIALIZATION, init_message_1_data)
    actorSystem.tell(number_agent_1, init_message_1)
```
